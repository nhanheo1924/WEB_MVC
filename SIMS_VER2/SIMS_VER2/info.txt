================================================================================
USE CASES
================================================================================

1. AUTHENTICATION & AUTHORIZATION
   - UC-001: User Login
     * Actors: Admin, Student, Faculty
     * Description: User can log in with username and password
     * Preconditions: User account exists and is active
     * Postconditions: User is authenticated and redirected to appropriate dashboard
   
   - UC-002: User Registration
     * Actors: Student (self-registration)
     * Description: New student can register for an account
     * Preconditions: None
     * Postconditions: New student account created with ACTIVE status
   
   - UC-003: User Logout
     * Actors: All authenticated users
     * Description: User can log out from the system
     * Preconditions: User is authenticated
     * Postconditions: User session is terminated

2. ADMIN USE CASES
   - UC-004: Manage Students
     * Create, Read, Update, Delete student records
     * View student details
     * Edit all student information
   
   - UC-005: Manage Courses
     * Create, Read, Update, Delete course records
     * View course details
     * Edit all course information
   
   - UC-006: Manage Course Offerings
     * Create, Read, Update, Delete course offerings
     * Assign instructors to course offerings
     * Manage student enrollments in course offerings
     * View offering details

3. STUDENT USE CASES
   - UC-007: Browse Available Courses
     * View available course offerings
     * Filter by program
     * View course details (instructor, schedule, enrollment status)
   
   - UC-008: Enroll in Course
     * Enroll in available course offerings
     * Check enrollment capacity
     * View enrollment status
   
   - UC-009: View My Courses
     * View enrolled courses
     * View course details
     * View grades for completed courses
   
   - UC-010: View Grades
     * View academic transcript
     * View GPA calculation
     * View individual course grades
   
   - UC-011: Edit Profile
     * Edit basic profile information (FullName, DateOfBirth, Gender, Email, Phone, Address)
     * Cannot edit StudentCode, Program, Intake, Status

4. FACULTY USE CASES
   - UC-012: View My Course Offerings
     * View assigned course offerings
     * View enrollment statistics
     * View offering status
   
   - UC-013: Manage Students & Grades
     * View enrolled students in course offerings
     * Enter/Update student grades (0-10 scale)
     * View student information
     * Clear grades if needed
   
   - UC-014: Edit Profile
     * Edit username
     * View profile information

DATABASE SCHEMA
================================================================================

Tables:
1. Users
   - Id (PK, int, identity)
   - Username (nvarchar(50), unique, not null)
   - PasswordHash (nvarchar(255), not null)
   - Role (int, not null) - 0: Admin, 1: Student, 2: Faculty
   - Active (bit, default: 1)

2. Students
   - Id (PK, int, identity)
   - StudentCode (nvarchar(10), unique, not null)
   - FullName (nvarchar(100), not null)
   - DateOfBirth (date, nullable)
   - Gender (nvarchar(10), nullable)
   - Email (nvarchar(100), nullable)
   - Phone (nvarchar(20), nullable)
   - Address (nvarchar(200), nullable)
   - Program (nvarchar(50), nullable)
   - Intake (nvarchar(20), nullable)
   - Status (nvarchar(20), default: 'ACTIVE')
   - UserId (FK to Users.Id, nullable)

3. Courses
   - Id (PK, int, identity)
   - CourseCode (nvarchar(20), unique, not null)
   - CourseName (nvarchar(100), not null)
   - Description (nvarchar(500), nullable)
   - Credits (int, not null)
   - Program (nvarchar(50), nullable)
   - Type (nvarchar(20), nullable) - 'CORE' or 'ELECTIVE'

4. CourseOfferings
   - Id (PK, int, identity)
   - CourseId (FK to Courses.Id, not null)
   - Semester (nvarchar(20), not null)
   - Year (int, not null)
   - ClassCode (nvarchar(20), not null)
   - InstructorUserId (FK to Users.Id, nullable)
   - MaxStudents (int, not null)
   - Status (nvarchar(20), default: 'OPEN')
   - Unique constraint: (CourseId, Semester, Year, ClassCode)

5. Enrollments
   - Id (PK, int, identity)
   - StudentId (FK to Students.Id, not null)
   - CourseOfferingId (FK to CourseOfferings.Id, not null)
   - Status (nvarchar(20), default: 'ENROLLED')
   - Grade (decimal(5,2), nullable) - Scale 0-10
   - Unique constraint: (StudentId, CourseOfferingId)

================================================================================
AUTHENTICATION & AUTHORIZATION
================================================================================

Authentication Scheme: Cookie Authentication
- Login Path: /Auth/Login
- Access Denied Path: /Auth/AccessDenied
- Cookie Expiration: 7 days

Roles:
1. Admin
   - Full system access
   - Manage students, courses, course offerings
   - Manage enrollments

2. Student
   - Browse and enroll in courses
   - View own courses and grades
   - Edit own profile (limited fields)

3. Faculty
   - View assigned course offerings
   - Manage students and grades in assigned courses
   - Edit own profile (username only)

Password Hashing: SHA256 + Base64 encoding
